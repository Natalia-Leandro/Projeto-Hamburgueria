# 🍔 Projeto Hamburgueria — React Native + Expo

Aplicação acadêmica de delivery desenvolvida com **React Native**, **Expo**, **TypeScript** e **Expo Router**.

O projeto simula uma hamburgueria digital com navegação entre categorias, carrinho de compras, promoções e cálculo do valor total do pedido.

## 🚀 Tecnologias utilizadas

- React Native
- Expo
- TypeScript
- Expo Router
- React Hooks
- Local Storage
- API REST / Fetch
- Git e GitHub

## ✨ Funcionalidades

- Navegação entre categorias de produtos
- Visualização de hambúrgueres, pizzas, bebidas, doces e outros itens
- Tela de promoções consumindo dados de uma API
- Adição de produtos ao carrinho
- Contador de itens no carrinho
- Cálculo do valor total
- Limpeza do carrinho
- Persistência dos itens no armazenamento local
- Navegação entre telas com Expo Router

## 📁 Estrutura principal

```text
app/
├── index.tsx
├── lista.tsx
├── carrinho.tsx
├── promocoes.tsx
├── pizzas/
├── bebidas/
├── doces/
├── outros/
└── database/
```

## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/Natalia-Leandro/Projeto-Hamburgueria.git
```

Entre na pasta do projeto:

```bash
cd Projeto-Hamburgueria
```

Instale as dependências:

```bash
npm install
```

Inicie o projeto:

```bash
npx expo start
```

## 🎯 Objetivo do projeto

Praticar conceitos de desenvolvimento mobile, componentização, navegação, gerenciamento de estado, consumo de API, persistência de dados e versionamento com Git/GitHub.
